# Цель проекта

## Мы будем строить систему автоматического формирования графика смен операторов чат-поддержки.

### На входе:
- история обращений (qwery.csv);
- список смен (Смены);
- список экспертов (Список экспертов).

### На выходе:
- анализ нагрузки;
- расчет необходимого количества экспертов;
- оптимальное распределение по сменам;
- график работы на месяц;
- проверка покрытия;
- Excel-отчет.

#### Все будет запускаться одной командой:
python main.py
